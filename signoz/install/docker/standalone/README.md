# SigNoz — Docker standalone

SigNoz documents Docker standalone installation for local/self-hosted use. Follow the official versioned command and environment requirements rather than copying a Compose cluster profile.

Official guide: [Install SigNoz on Docker](https://signoz.io/docs/install/docker/).

The repository's reproducible benchmark asset is the multi-container [Docker Compose standalone setup](../../docker-compose/standalone/), not this documentation-only upstream mode.
