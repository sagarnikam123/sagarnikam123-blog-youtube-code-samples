# VictoriaMetrics stack — operator cluster

Install the official VictoriaMetrics Operator, then apply `VMCluster`, `VMAgent`, `VMAlert`, and scrape custom resources for a distributed Kubernetes deployment.

The operator is also included by the official K8s Stack chart. Prefer the chart for a bundled install; use this mode when the operator lifecycle is managed separately.

Official sources: [VM Operator](https://docs.victoriametrics.com/helm/victoria-metrics-operator/), [Operator quick start](https://docs.victoriametrics.com/guides/getting-started-with-vm-operator/).
