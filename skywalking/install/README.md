# Apache SkyWalking installation modes

The repository already contains the complete SkyWalking installation set:

| Mode | Path |
|:-----|:-----|
| Binary standalone | [`binary-standalone/`](binary-standalone/) |
| Docker standalone | [`docker-standalone/`](docker-standalone/) |
| Docker cluster | [`docker-cluster/`](docker-cluster/) |
| Kubernetes Helm | [`kubernetes-helm/`](kubernetes-helm/) |
| Kubernetes SWCK operator | [`kubernetes-swck/`](kubernetes-swck/) |

The Docker standalone path is used for local validation; Kubernetes Helm/SWCK paths cover the Phase 2 cluster deployment.
