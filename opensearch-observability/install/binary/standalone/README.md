# OpenSearch Observability — native components

OpenSearch publishes native distributions/packages for OpenSearch and OpenSearch Dashboards. Data Prepper is installed separately as the OTLP and pipeline component.

Official installation guides:

- [OpenSearch installation](https://opensearch.org/docs/latest/install-and-configure/install-opensearch/index)
- [OpenSearch Dashboards installation](https://opensearch.org/docs/latest/install-and-configure/install-dashboards/index/)
- [Data Prepper documentation](https://opensearch.org/docs/latest/data-prepper/)

Configure the three components to use the same OpenSearch endpoint and secure them before production use. The repository's Compose stack remains the reproducible single-node benchmark path.
