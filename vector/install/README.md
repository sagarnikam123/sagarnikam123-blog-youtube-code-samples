# Vector installation modes

| Mode | Status | Path | Notes |
|:-----|:-------|:-----|:------|
| Binary / install script | Available | [`binary/`](binary/) | curl install, APT, RPM, Homebrew |
| Docker / Docker Compose | Available | [`docker/`](docker/) | `timberio/vector` image |
| Helm (Kubernetes) | Available | [`helm/`](helm/) | Agent (DaemonSet) or Aggregator (StatefulSet) |
| Kubernetes DaemonSet (raw YAML) | Available | [`k8s/`](k8s/) | Plain manifests |

Official docs: [vector.dev/docs/setup/installation](https://vector.dev/docs/setup/installation/).
