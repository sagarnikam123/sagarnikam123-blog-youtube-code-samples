# ClickStack — HyperDX only

Run HyperDX against an existing ClickHouse deployment and MongoDB application-state database. This mode does not provision ClickHouse or ingest telemetry; configure your own collectors and pipelines.

Use the official deployment instructions and environment configuration from [HyperDX only](https://clickhouse.com/docs/clickstack/deployment/hyperdx-only).

This mode is appropriate when ClickHouse and ingestion are already operated separately. It is not the repository's benchmark path.
