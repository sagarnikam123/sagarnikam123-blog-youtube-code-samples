# ClickStack — ClickHouse-embedded mode

ClickStack can be accessed from the ClickHouse server binary without deploying separate ClickStack components. This mode is intended for demos and evaluations and does not provide the full production feature set.

Follow the current platform-specific ClickHouse binary download and startup commands in [Embedded in ClickHouse](https://clickhouse.com/docs/clickstack/deployment/clickhouse-embedded).

This is an embedded ClickHouse distribution, not a standalone ClickStack executable.
